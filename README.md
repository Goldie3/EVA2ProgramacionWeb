Primero que nada se tiene que abrir el scrip de mysql, importalo en MySqlWorkbench y ejecuta el scrip entero, esto creara la base de datos con las
tablas que se piden.

Para poder correr la api, abre la carpeta back con visual studio code, abre una terminal e ingresa "node app.js" para poder iniciar la api.

Para poder probar los endpoints, inicia Postman, selecciona el json que viene en la carpeta raiz y arrastralo en el apartado izquierdo, esto importara los test de Postman.

Finalmente para cerrar la api simplemente se hace ctrl + c en la terminal.
